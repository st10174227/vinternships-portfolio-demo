# Personal project origin

VInternships is Mohammed Ba Yazed's personal continuation of an ASP.NET university project, provided as `VInternships-Source-20261121-153917.zip` on 21 November 2026.

The original app implements company CRUD, student creation/listing and internship creation/listing, hours and feedback. This continuation retains those concepts and record fields, replacing the SQL Server dependency with fictional, per-browser temporary records for a public portfolio demo.

Personal additions include a new responsive interface, complete student management, placement details/edit/delete, server validation, additive hour logging, stale-form protection, protected mutation forms, sample data, browser isolation, reset/expiry/capacity limits, checks and deployment preparation. These additions should not be represented as the original university submission.

The installer creates a new `VInternships-Personal` directory. It does not modify the academic source, run Git commands or publish anything. `docs/SOURCE-MANIFEST.json` identifies every file in the supplied source with its SHA-256 hash. Third-party asset licenses remain in `VInternships/wwwroot/lib`.
